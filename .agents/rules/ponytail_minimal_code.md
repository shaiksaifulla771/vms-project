# Project Rule: Ponytail Minimalist Code Standard

**Philosophy**: Write the simplest, shortest, cleanest, and most minimal code that completely solves the problem.

### Core Principles:
1. **Zero Bloat & YAGNI**: Never write speculative abstractions, premature wrappers, or unnecessary intermediate layers. If a feature isn't needed right now, don't write code for it.
2. **Native First**: Use native JavaScript/Node/React capabilities over heavy third-party helper libraries whenever possible.
3. **One Line Over Fifty**: Favor concise, functional idioms (destructuring, optional chaining, nullish coalescing, standard array helpers) instead of verbose procedural boilerplate.
4. **Direct & Readable**: Keep functions focused, direct, and compact. Avoid multi-layer indirection.
5. **Preserve Integrity**: Always maintain essential business logic, database transactions, error handling, and RBAC access guards while minimizing lines of code.
